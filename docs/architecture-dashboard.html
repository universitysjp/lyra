Lyra — Architecture Dashboard

Local-first music backend. Audio never leaves the phone; only ID3 metadata is synced. Microservices talk over RabbitMQ (MassTransit), PostgreSQL holds state (database per service), Redis caches libraries, and a YARP gateway fronts the public API.

Lyra.Identity.Api

REST :5001 · private gRPC :5004

  • Register / login / refresh / logout, RSA-signed JWTs
  • BYOK AI connection, API key encrypted at rest
  • identity_db (PostgreSQL)
  • Data Protection keys persisted in DB

catalog

Lyra.Catalog.Api

REST :5002

  • Batch import, fingerprint = SHA-256(title+artist+duration)
  • Global tracks + per-user user_tracks
  • Fuzzy search via pg_trgm GIN, always user-scoped
  • Redis cache-aside + per-user version bump
  • Consumes lyrics + enrichment events
  • Migrations: automatic at startup
worker

Lyra.Enrichment.Worker

Background consumer · no HTTP port

  • LRCLIB lookup: exact, then scored v2 search
  • Publishes lyrics event before any AI call
  • LLM extraction: mood, themes, energy 1–10
  • PrefetchCount=3 + exponential retry
  • Fetches user key over internal gRPC

Lyra.PlaylistRag.Api

REST :5003 · currently a stub

  • Planned: embeddings into vector_db (pgvector HNSW)
  • Planned: prompt rewrite → filtered similarity search → LLM sequencing
  • Only /api/playlists/ping implemented

Enrichment pipeline

1
Client syncs metadata

POST /api/catalog/tracks/batch → dedupe by fingerprint, write track + link + outbox in one transaction → 202 Accepted.

2
SongImportedEvent

Published through the MassTransit EF Core transactional outbox. Worker consumes with low prefetch.

3
Lyrics from LRCLIB

Exact lookup first; on 404, score candidates (title 55% / duration 30% / artist 15%), threshold 85, fetch top candidates. Transient failures retry via MassTransit.

4
SongLyricsFetchedEvent

Published immediately so lyrics survive an AI failure. Catalog stores plain/synced lyrics plus canonical LRCLIB metadata.

5
AI categorization

Worker resolves the caller's encrypted AI connection over private gRPC, then asks for structured output: PrimaryMood, Themes[], EnergyLevel.

6
SongEnrichedEvent

Catalog flips isEnriched and invalidates the user's cached pages; RAG (future) embeds and upserts into pgvector.

7
Playlist generation (planned)

POST /api/playlists/generate → prompt rewrite → user-scoped similarity search → LLM selects order → returns local track IDs.

Run it

docker compose up -d postgres rabbitmq redis

# first time only (Identity does not auto-migrate)
dotnet ef database update --project Lyra.Identity.Api

dotnet run --project Lyra.Identity.Api      # :5001 + :5004
dotnet run --project Lyra.Catalog.Api       # :5002 (auto-migrates)
dotnet run --project Lyra.Enrichment.Worker # background
dotnet run --project Lyra.Gateway           # :5000 (if free)
AI keys are per-user, not in .env. Save one via PUT /api/auth/ai-connection before expecting enrichment to complete.
